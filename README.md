# PenScript

## Структура проекта
```
PenScript/
├───api/                     # Реализация API на Go
├───data/                    # Датасеты и подготовленные данные
│   ├───processed/           # Предобработанные изображения
│   ├───raw/                 # Исходные изображения
│   ├───test/                # Тестовый набор данных
│   ├───train/               # Обучающий набор данных
│   ├───val/                 # Валидационный набор данных
├───models/                  # Сохранённые модели
├───src/                     # Исходный код проекта
│   ├───data_preprocessing.py # Подготовка данных
│   ├───train_text_recog.py   # Обучение OCR модели
│   ├───train_writer_ident.py # Обучение классификатора почерка
│   ├───infer.py              # Скрипт для тестирования моделей
│   ├───utils.py              # Вспомогательные функции
├───README.md                # Документация проекта
```
